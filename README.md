# BLAKKBOX

OEM-preserving DENSO Diesel ECU calibration framework.

## Features

- ROM validation
- ECU fingerprinting
- Delta extraction
- Calibration map detection
- Delta filtering
- Engineering validation
- Report generation

## Supported

- Toyota DENSO
- Mitsubishi DENSO
- Nissan DENSO
- Mazda DENSO
